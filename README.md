# 🪶 Green Smart School CAD Web V19 (Total Freedom)

학교 공간재구조화(그린스마트 미래학교) 전문 2D CAD 및 3D 입체 투시도 웹 애플리케이션입니다.  
기존 학교 건축 도면 사진을 배경에 얹고, 자석 스냅(Snap) 기반 교실 배치, 마우스 우클릭 내부 가구 인테리어, Gemini AI 공간 자동 설계 및 3D WebGL 투시도까지 완벽하게 지원합니다.

---

## 🚀 GitHub Pages 배포 시 즉시 실행 방법

이 저장소는 루트에 `index.html`이 배치되어 있어, **GitHub Pages 기능을 켜면 별도 서버나 빌드 과정 없이 전 세계 누구나 웹 브라우저에서 바로 사용**할 수 있습니다.

### 📌 1분 설정 가이드
1. 이 프로젝트 폴더를 본인의 GitHub 저장소(Repository)에 **Push(업로드)**합니다.
2. GitHub 저장소 페이지에서 상단 **[Settings]** 탭을 클릭합니다.
3. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
4. **Build and deployment** 섹션에서:
   - **Source:** `Deploy from a branch` 선택
   - **Branch:** `main` (또는 `master`) / `/ (root)` 선택 후 **[Save]** 클릭
5. 약 30초~1분 뒤 상단에 생성되는 **`https://<깃허브계정>.github.io/<저장소이름>/`** 링크를 클릭하면 즉시 전 세계 어디서든 웹 CAD가 실행됩니다!

## 🌟 주요 기능 안내

1. **CAD 다크 테마 & 자석 스냅(Snap):**
   - 100cm 단위 정밀 그리드 (#212121)
   - 교실 모서리 및 변끼리 20px 이내 접근 시 자동으로 달라붙는 자석 스냅 기능
   - 상단 및 좌측 노란색 치수선 화살표 표기 (`<--- 900cm --->`, `750cm`)
   - 방 중앙 녹색 표기 (`일반교실 900x750`)

2. **🖼 배경 도면 사진 로드:**
   - 학교 체육관, 강당, 교사동 도면 사진을 캔버스 배경에 깔고 투명도(0~100%) 조절
   - 도면 위에 신규 재구조화 교실/공간을 직접 올려보는 건축 설계 기능

3. **🖱️ 마우스 우클릭: RoomEditor 내부 가구 꾸미기:**
   - 교실 위 우클릭 시 가구 에디터 실행
   - 책상(60×40), 의자(40×40), 칠판(200×20), 사물함, 교탁, TV, 문, 창문 배치
   - 가구 드래그 이동 및 우클릭 삭제

4. **✨ Gemini AI 도면인식 & 공간재구조화:**
   - 도면 사진과 교육 요구사항을 분석하여 다목적 코어, 무대, 실감탐구실 등 자동 배치

5. **🧊 3D 입체 투시도 (Three.js WebGL):**
   - 1F~4F 층별 교실 벽체와 내부 배치 가구들을 3D 입체로 즉시 변환하여 360도 회전 탐색

## ⌨️ 단축키
- **좌클릭 드래그:** 방 선택 및 이동 (인접 교실 자석 스냅)
- **우클릭:** 방 내부 가구 꾸미기 (RoomEditor)
- **마우스 휠:** 도면 줌 인 / 줌 아웃
- **화면 빈 곳 드래그:** 도면 패닝 (이동)
- **Delete:** 선택된 방 삭제
- **Ctrl + Z:** 실행 취소 (Undo)
- **Ctrl + Y:** 다시 실행 (Redo)
- **Ctrl + S:** 프로젝트 JSON 파일 다운로드
